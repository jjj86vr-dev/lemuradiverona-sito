Il pannello del muratore

Aggiungi, togli e correggi mattoni e pietre senza toccare il codice.

Come funziona (e perché non c'è una password). Il muro è una pagina senza server: i dati vivono dentro index.html. Questo pannello legge quel file, ti fa fare le modifiche, e ti riconsegna il file aggiornato da pubblicare. Da solo non cambia niente online — la chiave vera è il tuo account GitHub: solo chi può fare git push può murare davvero.

1 · Carica il muro

Scegli il file index.html dalla cartella Documents\lemuradiverona\presale del tuo PC.

5 · Pubblica

Scarica il file aggiornato, poi incolla queste righe in PowerShell:

cd $HOME\Documents\lemuradiverona
Copy-Item $HOME\Downloads\index.html presale\index.html -Force
git add presale/index.html
git commit -m "Aggiorno il muro"
git push

Prima di pubblicare puoi aprire il file scaricato col browser e controllare che il muro sia come lo vuoi. Se il sito è collegato a GitHub via Netlify, dopo il push si aggiorna da solo.
